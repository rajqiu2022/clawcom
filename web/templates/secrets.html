📌 使用方式
1. 在这里加密存储你的外部 API Token / 密钥（如 Tavily / 企微 Webhook）
2. 在 Skill 内容里用占位符引用，例如：${SECRET:tavily_api_key}
3. Agent 运行时通过 Bearer Token 调 POST /api/v1/secrets/resolve 自动替换占位符为明文
4. 你可以查看/管理自己 user 名下、以及自己拥有的所有 OpenClaw 名下的所有密钥；其他用户和管理员均不可见明文
