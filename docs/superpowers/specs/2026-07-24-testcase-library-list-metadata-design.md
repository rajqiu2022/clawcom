# 用例库列表元信息精简设计

## 目标

左侧用例库树的用例库行不再显示作者、评审状态和共享状态，降低列表视觉噪声。

## 范围

- 移除用例库行的作者徽标。
- 移除用例库行的评审状态徽标。
- 移除用例库行的共享状态徽标。
- 移除子目录行的作者徽标，保持列表展示规则一致。
- 保留信息按钮、用例数量、新增目录、共享和评审操作按钮。
- 保留详情弹窗中的作者、评审及共享信息。
- 不修改后端接口、数据字段、权限和业务功能。

## 实现

只调整 `web/templates/testcases.html` 的列表树渲染逻辑，不再构造或插入上述三个展示徽标。共享与评审相关函数及弹窗继续保留，避免影响操作能力。

## 验证

- 用例库行和目录行不再出现作者名称。
- 用例库行不再出现“评审中”“已通过”“已拒绝”等状态。
- 用例库行不再出现“共享给我”“共享 N”等状态。
- 信息、数量、新增、共享和评审按钮仍可见且可操作。
- 详情弹窗仍能显示完整元信息。
