## V4.0 设计细化：上报机制 + Memos 隔离方案

**上报机制确定为方案 B**：OpenClaw 端定时推送
- 每个 OpenClaw 配 WorkBuddy automation，默认 15:00 + 21:00 两次上报
- 上报内容：完成任务 + 新增知识 + 经验记录 + AI 智能小结
- 频率可在 Web 管理系统配置修改

**Memos 用户隔离方案**：共用账号 + 标签区分
- 所有 OpenClaw 共用一个 Memos 账号
- `#claw-{name}` 标签区分归属（如 #claw-小测）
- `#shared` 标签控制共享（管理员审核通过后添加）
- 默认私有，审核后共享；查询时自动合并"自己的 + 已共享的"
- 完整标签：`#claw-{name} #scope-{level} [#project-XXX] [#module-YYY] #内容标签 [#shared]`

## 设计澄清：上报触发机制

**重要**：OpenClaw 的定时上报由 OpenClaw 自己管理，不绑定 WorkBuddy
- Web 管理系统只提供上报 API 接收数据 + 配置查询接口
- OpenClaw 根据自身运行环境选择定时方式（cron / APScheduler / automation / 系统定时等）
- 新增 API：`GET /api/v1/openclaws/{id}/config`，供 OpenClaw 拉取配置
